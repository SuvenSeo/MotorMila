# Contributing to Motormila

Motormila is proprietary software owned by Ardeno Studio. This repository
is public for review and for running GitHub Actions, not for open
contribution. See `LICENSE` and `NOTICE` before doing anything below.

## The short version

- **Do not submit pull requests** unless Ardeno Studio has first agreed
  in writing that you may contribute, and on what terms.
- **Do not copy, fork for reuse, or redistribute** this work. Forking on
  GitHub for private review does not grant any right to use the work
  outside GitHub.
- **Do not file issues containing other people's code, credentials, or
  personal data.** Issues are for feedback on the live product at
  https://motormila.vercel.app, and for reporting copies of this work.

## If Ardeno has agreed in writing that you may contribute

1. Work only in the scope Ardeno agreed, in writing.
2. Do not introduce third-party code under a licence Ardeno has not
   approved, and do not remove copyright or licence notices.
3. Your contribution is governed by that written agreement. If there is
   no written agreement, your contribution is **not** accepted, not
   licensed to Ardeno, and not merged — and Ardeno has no obligation
   to review it.

## Reporting a copy or a security issue

- A copy of this work presented as someone else's: email
  hello@ardenostudio.com with a link to the copy.
- A security issue in the live product: email hello@ardenostudio.com
  with enough detail to reproduce it, and do not publish it publicly
  before Ardeno has had a chance to fix it.
